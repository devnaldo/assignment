# Project: Apartment Project Website (Website Developer Intern Assignment)

## Goal
A premium, responsive, single-page real estate website for an apartment project
(2 BHK and 3 BHK residences). Built with plain HTML5 and CSS3.

## Tech rules
- Only HTML5, CSS3 and minimal vanilla JavaScript. No frameworks, no build tools.
- Files: index.html, style.css, script.js (only if needed), images/ folder.
- Use semantic HTML (header, nav, main, section, footer).
- Use CSS variables for colors and fonts, defined in :root.
- Mobile-first CSS. Breakpoints at 768px and 1024px.
- Every image needs descriptive alt text.
- Comment each major section in HTML and CSS.
- Keep code clean, consistently indented (2 spaces), no unused CSS.

## Design standard
- Colors: forest green #1F3D2B, ivory #FAF6EC, champagne gold #C9A96E,
  dark text #1A1A1A.
- Fonts (Google Fonts): Playfair Display for headings, Poppins for body.
- Feel: premium, luxurious, calm, lots of whitespace, subtle hover effects.
- Gold used for accents, borders and buttons only. Don't overuse it.

## Required sections (in this order)
1. Header and navigation (logo, menu, contact number/button)
2. Hero banner with apartment visual, headline, CTA button
3. Project highlights
4. Project overview
5. 2 BHK and 3 BHK residences
6. Amenities
7. Project photo gallery
8. Location and connectivity
9. Enquiry and contact form
10. Footer with branding and social links

## Images
- All images are in ./images. Use only these files. Do not hotlink external images.
- Don't rename or delete images.

## Workflow
- Make small, focused changes and explain what you changed.
- Test layout at 1440px, 768px and 375px widths before saying a task is done.
- Don't add libraries or dependencies without asking.
- Use placeholder project name/details that are easy to edit, marked with
  comments like <!-- EDIT: project name -->.
